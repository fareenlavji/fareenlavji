## About Me

Software Engineering student at **Carleton University** and freelance IT consultant specializing in cybersecurity, enterprise architecture, and accessible system design.

I help organizations strengthen security postures, streamline operations, and navigate digital transformation—from healthcare nonprofits implementing compliance frameworks to local businesses optimizing workflows.

- 🎓 **Recent work:** Security Evaluations Management Asset (SEMA)—reverse-engineered Common Criteria to design a collaborative document editor for cybersecurity certification
- 🔬 **Research interests:** Human-computer interaction, healthcare database accessibility, gamification in security
- 📍 **Based in:** Ottawa, ON, Canada
- ⚡ **Beyond code:** Archery, lock-picking, natural perfumery, vintage photography
